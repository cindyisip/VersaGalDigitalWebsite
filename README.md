# VersaGal Digital Website

Static website prepared for GitHub Pages at `versagaldigital.com`.

## Site structure

- `/` — VersaGal Digital homepage
- `/apps/` — digital apps, beginning with VersaLink
- `/music/` — music catalog landing page
- `/about/` — brand story and contact information
- `/apps/versalink/privacy/` — VersaLink privacy policy
- `/apps/versalink/support/` — VersaLink support page

## Before publishing

1. Configure `support@versagaldigital.com` and `privacy@versagaldigital.com` forwarding in Porkbun.
2. Upload the contents of this folder to the root of a GitHub repository.
3. Enable GitHub Pages from the repository's main branch and root folder.
4. Connect the Porkbun DNS records to GitHub Pages.
5. After HTTPS becomes available in GitHub Pages, enable **Enforce HTTPS**.

No framework, build process, analytics, cookies, or paid hosting is required.
